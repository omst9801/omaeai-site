OMAE JARVIS Calendar

A private macOS desktop application that connects the owner's Google Calendar to JARVIS, the owner's personal assistant.

Private application. OMAE JARVIS Calendar is used only by its owner, with the owner's own Google account. It has no public sign-up and is not offered to other users.

What it does

  • Reads the schedule. It answers questions such as "What's on my calendar tomorrow?" or "Which events require my attention?".
  • Checks availability. It answers questions such as "Am I available Friday afternoon?" and finds free time.
  • Manages events with the owner's approval. It can prepare to create, move, rename or cancel an event, but nothing changes until the owner approves that exact change in a native macOS dialog on their Mac. Higher-risk changes need a typed confirmation code as well. These include changes to recurring events, to events with other attendees, and to events that start within the next 24 hours.

How it works

  • The owner connects their Google account once with Google's standard sign-in for desktop apps (OAuth 2.0 with PKCE and a loopback redirect on the Mac). The owner's Google password is never seen or stored.
  • The sign-in credentials are kept in the macOS Keychain on the owner's Mac.
  • Calendar requests are interpreted by code that runs on the Mac. No AI model receives Google Calendar data.
  • Changes are checked on the Mac before anything is sent to Google: each one gets a single-use approval that expires, and there is an emergency STOP ALL switch.
  • The owner can disconnect at any time. Disconnecting revokes access at Google and deletes the stored credentials.

Google permissions requested

PermissionWhy
calendar.calendarlist.readonlyTo see which calendars the owner has, so JARVIS can tell personal, business and shared calendars apart.
calendar.eventsTo read events, and to create, change or delete an event only when the owner approves that specific change.

It requests no other Google data: no Gmail, Drive, Contacts or profile access.
